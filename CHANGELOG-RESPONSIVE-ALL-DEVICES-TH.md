# AVSF v3.2.4 — Responsive All-Devices Layout

- Added a coordinated responsive layout layer for phone, tablet portrait, tablet landscape, and desktop.
- Keeps AVSF's existing viewport-family detection and server-side card-column settings; mobile remains two columns.
- Standardizes shared post grids, card image ratios, title/meta slots, and recommendation carousel sizing.
- Makes the single-post poster and metadata responsive: mobile stacks a centered poster above a full-width metadata panel; tablets/desktops use a balanced side-by-side layout.
- Metadata rows and taxonomy chips wrap safely without squeezing the panel or causing horizontal overflow.
- Reduces the floating language dock footprint on smaller devices.
- Adds safe-area-aware bottom navigation spacing and a common centered content canvas.
- Presentation-only update: no post data, routes, database schema, upload names, or player playback code changed.
