AVSF v3.2.4 — Post Card Metadata One-Row Fix
ผู้พัฒนา: B-NTP

แพตช์นี้แก้แถวข้อมูลใต้ชื่อเรื่องในการ์ดวิดีโอให้แสดงในบรรทัดเดียวกัน:
- หมวดหมู่อยู่ชิดซ้าย
- วันที่เผยแพร่อยู่ชิดขวา
- ป้องกัน flex-wrap ทำให้วันที่ตกลงบรรทัดใหม่
- หากชื่อหมวดหมู่ยาว จะย่อด้วย ellipsis โดยไม่ดันวันที่
- แสดงวันที่ในตำแหน่งเดียวกันทั้งหน้าแรกและหน้ารายการ
- แท็กเพิ่มเติม (ถ้ามี) คงแสดงในแถวแยกด้านล่าง

ไฟล์ที่แก้:
1. avsf-frontend/partials/head.php
2. avsf-frontend/loop-templates/content-post-card.php

ติดตั้ง:
1. สำรองไฟล์เดิมก่อน
2. แตก ZIP ที่ Document Root และอนุญาตให้เขียนทับ 2 ไฟล์ตามโครงสร้าง
3. ล้าง cache ของ AVSF, Hosting และ CDN (ถ้ามี)
4. เปิดหน้ารายการใหม่และตรวจบนมือถือ

แพตช์นี้ไม่เปลี่ยนฐานข้อมูล ไม่แก้ข้อมูลโพสต์ และไม่แตะไฟล์รูปภาพ
