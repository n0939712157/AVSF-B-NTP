AVSF — PRIVATE HOST CONFIG BACKUP
==================================

ภายใน ZIP มี config.local.php ที่กู้คืนแบบ byte-for-byte จากไฟล์ AVSUBFIN.zip
ที่ผู้ใช้ส่งให้ก่อนหน้านี้ (รายการต้นทาง: htdocs/config.local.php)

สำคัญ:
- ไฟล์นี้มีข้อมูลเชื่อมต่อฐานข้อมูลและ install nonce ถือเป็นความลับ
- ห้ามเผยแพร่ ห้ามส่งต่อ และห้ามวาง ZIP นี้ไว้ใน public_html/Document Root
- เมื่อใช้กู้คืน ให้แตกเฉพาะ config.local.php ไปไว้ที่ Document Root ของ AVSF
- ตรวจสอบค่าการเชื่อมต่อกับ Hosting ก่อนใช้งาน เพราะนี่คือค่าจาก snapshot ที่ส่งมา
- ใน AVSUBFIN.zip ไม่พบ .env และ .user.ini จึงไม่ได้สร้างหรือใส่ไฟล์ปลอมไว้ในชุดนี้
- ไฟล์นี้ไม่ใช่ฐานข้อมูลสำรอง และไม่สามารถกู้ข้อมูล MySQL ได้ด้วยตัวเอง
