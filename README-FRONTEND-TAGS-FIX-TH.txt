AVSF v3.2.4 — Frontend Cards & Tag Import Fix
ผู้พัฒนา/ผู้เผยแพร่: B-NTP
ประเภทแพ็กเกจ: Overlay update patch สำหรับเว็บ AVSF ที่ติดตั้งอยู่แล้ว

สิ่งที่แก้ไข
1) การ์ดหน้ารวมค่าย / นักแสดง / แท็ก
   - นำภาพ SVG แบบเส้นร่างค่ายและเงารูปผู้หญิงออก
   - ใช้พื้นหลัง Cinematic gradient, soft spotlight, เส้นฟิล์มและวงแสงแบบนามธรรม
   - ไม่มีภาพซิลูเอตบุคคลแบบวาดการ์ตูน
   - หากรายการมีโลโก้ค่ายหรือรูปนักแสดงจริง ระบบยังแสดงภาพจริงตามเดิม

2) ระบบนำเข้าแท็ก
   - รองรับชื่อหัวคอลัมน์ Tag, Tags, Post Tag, post_tag, Post Tags,
     Tag Name, Tag Names และหัวข้อภาษาไทย เช่น แท็ก / แทก / ป้ายกำกับ
   - รองรับ CSV ที่คั่นด้วย comma, semicolon, tab หรือ pipe
   - รองรับรายการแท็กที่คั่นด้วย comma, semicolon, pipe หรือขึ้นบรรทัดใหม่
   - รองรับค่าแท็กที่ส่งมาเป็น JSON array
   - สร้าง/ค้นหา term ในตาราง tags และบันทึก ID ลง posts.tagIds
   - แสดงจำนวนแท็กในผลการบันทึก เพื่อให้ตรวจสอบได้ทันที
   - ถ้าไฟล์นำเข้าไม่มีแท็ก ระบบจะรักษา tagIds เดิมของโพสต์ไว้ ไม่ล้างค่าเดิมโดยไม่ตั้งใจ

3) ระบบนำเข้ารูปภาพ
   - คงการอัปเดต Image Import ล่าสุด: เลือกหลายภาพ/จับคู่ Code/นำเข้ารูปย้อนหลัง
   - รักษาชื่อไฟล์ต้นฉบับ โดยไม่มี hash/เลขสุ่มต่อท้ายชื่อไฟล์ที่บันทึกจริง

ไฟล์ที่อยู่ในแพ็กเกจ
- avsf-admin/index.php
- avsf-admin/modules/import.php
- avsf-core/import/post_import_parser.php
- avsf-core/import/avsf-image-matcher.php
- avsf-frontend/partials/head.php

วิธีติดตั้ง
1) สำรองไฟล์และฐานข้อมูล AVSF ปัจจุบันก่อนทุกครั้ง
2) แตก ZIP นี้ที่ Document Root ของ AVSF โดยคงโครงสร้างโฟลเดอร์
3) อนุญาตให้เขียนทับเฉพาะไฟล์ 5 ไฟล์ตามรายการด้านบน
4) ไม่ต้องนำเข้า SQL และไม่ต้องลบ config.local.php, uploads หรือข้อมูลเดิม
5) ล้าง Page Cache / OPcache ถ้า Hosting เปิดใช้อยู่ แล้วรีเฟรชหน้า /studio_list และ /actor_list

การเติมแท็กให้เรื่องที่มีอยู่แล้ว
- ข้อมูลสำรองที่ตรวจพบ MFYD-190 มี posts.tagIds เป็น [] จริง จึงไม่มี ID ให้หน้าเรื่องเดี่ยวแสดง
- แพตช์นี้ไม่เดาแท็กจากชื่อเรื่องหรือเนื้อหา เพราะอาจทำให้ติดแท็กผิด
- สำหรับโพสต์ที่เผยแพร่แล้ว ให้ใช้เมนูนำเข้าข้อมูลจำนวนมาก (Bulk Import) พร้อมไฟล์ต้นทางที่มี Code และคอลัมน์ Tag/Tags เพื่ออัปเดตโพสต์เดิมด้วย Code
- ระบบจะเชื่อมแท็กกับเรื่องเดิมและแสดงเป็นป้ายแท็กในหน้าเรื่องเดี่ยว เมื่อ posts.tagIds ถูกบันทึกแล้ว
- Quick Draft แบบ Advanced ใช้สำหรับสร้าง/อัปเดต Draft เท่านั้น และยังไม่เขียนทับโพสต์ Published ที่มีอยู่

การตรวจสอบ
- ตรวจ Syntax PHP และทดสอบ parser ด้วยตัวอย่าง CSV comma/semicolon/tab, JSON array และข้อความแบบ Code/Tag
- ยังไม่ได้ทดสอบ Transaction กับ MySQL จริงหรือทดสอบบน Hosting ของผู้ใช้ จึงควรทดลองบน Staging ก่อนอัปเดต Production
