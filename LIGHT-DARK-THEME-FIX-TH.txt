AVSF v2.0.3 — LIGHT MODE / DARK MODE CONSISTENCY FIX
ผู้พัฒนา: B-NTP

สิ่งที่แก้ไข
- โหมดสว่างใช้พื้นหลังขาว/เทาอ่อนในหน้ารายการโพสต์, ชุดคีย์เวิร์ด, File Manager และหน้า Data Transfer
- แผงอัปเดต ZIP, กล่อง Preview, ปุ่มรอง, ตาราง, File Editor และพื้นที่แก้ไขไฟล์ เปลี่ยนตามโหมด
- โหมดมืดยังคงใช้พาเลตดำ/เทาเข้มเดิม
- File Manager อ่านค่า avsf-admin-theme จาก localStorage เพื่อใช้ธีมเดียวกับหลังบ้าน
- Data Transfer อ่านค่า avsf-admin-theme เดียวกัน แทนการบังคับใช้โหมดมืดเป็นค่าเริ่มต้น
- ปรับสีข้อความและป้ายสถานะให้มี contrast ที่เหมาะกับพื้นหลังสว่าง
- ไม่เปลี่ยนโครงสร้างฐานข้อมูล เนื้อหา หรือระบบสิทธิ์

ไฟล์ที่เปลี่ยน
- website/avsf-admin/index.php
- website/avsf-admin/modules/file-manager.php
- website/avsf-admin/modules/data-transfer.php
- manifest.json (คำอธิบายแพ็กเกจ)

ติดตั้งแบบ Patch
1. สำรองไฟล์เดิมก่อนทุกครั้ง
2. แตก ZIP โดยคงโครงสร้าง website/ ไว้
3. นำ file-manager.php ไปแทนที่ avsf-admin/modules/file-manager.php
4. นำ data-transfer.php ไปแทนที่ avsf-admin/modules/data-transfer.php
5. ล้างแคชหน้าแอดมิน/เบราว์เซอร์ แล้วเปิดหน้าใหม่

การทำงานของธีม
- ใช้ค่า localStorage key: avsf-admin-theme
- ค่า light = โทนขาว/สว่าง
- ค่า dark = โทนดำ/มืด
- หากไม่มีค่า จะเริ่มต้นเป็นโหมดสว่าง

การตรวจสอบ
- ตรวจ PHP Syntax ด้วย php -l แล้ว
- ตรวจโครงสร้าง ZIP แล้ว
- ยังไม่ได้ทดสอบ visual regression บนอุปกรณ์จริงหรือ production hosting
