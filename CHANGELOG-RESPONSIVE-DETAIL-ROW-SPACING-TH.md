# AVSF v3.2.4 — Responsive Detail Row Spacing Refinement

- Reduced the horizontal gap between metadata labels and their value chips in the single-post details panel.
- Mobile uses a compact 40px/10% label rail and 4px column gap to move the first chip left toward the marked reference position.
- iPad portrait/landscape uses a 76px/15% responsive label rail and 7px gap.
- Desktop uses a 110px to 180px fluid label rail and 10px gap; wide desktop caps the label rail at 160px.
- Labels and value chips remain separate columns; tags wrap naturally and long values break safely rather than overflowing.
- Tightened only the vertical padding within the metadata rows slightly.
- No change to post-card grids, poster frame, Gallery, preview behavior, post data, taxonomy, routes, database, or player.
