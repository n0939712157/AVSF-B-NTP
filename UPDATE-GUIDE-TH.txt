AVSF v3.2.6 — FULL OVERLAY UPDATE
Developer / Publisher: B-NTP

วิธีอัปเดตเว็บเดิม
1. สำรองไฟล์เว็บไซต์และฐานข้อมูลปัจจุบันให้ครบก่อน
2. ทดสอบ ZIP บน Staging ก่อนใช้งาน Production
3. แตก ZIP นี้ลงใน Document Root ของ AVSF เดิม และอนุญาตให้เขียนทับไฟล์แอปพลิเคชันที่ชื่อซ้ำ
4. ห้ามลบไฟล์เดิมก่อนแตก ZIP
5. เก็บ config.local.php และฐานข้อมูลเดิมไว้
6. เก็บไฟล์เดิมทั้งหมดภายใน avsf-storage/uploads/ โดยเฉพาะรูปที่อัปโหลดจริง
7. ZIP นี้ไม่รวม Database dump, credentials, user uploads, backup archives, logs, cache หรือ quarantine runtime files
8. หลังอัปเดตให้ล้าง AVSF HTML Cache และล้าง Hosting/CDN Cache แยกต่างหาก หากใช้งานอยู่
9. ทดสอบหน้าบ้าน หลังบ้าน, URL เดิม, Admin, File Manager, Import/Export, SEO, Sitemap, Robots, Upload และ Backup/Restore

รายการปรับปรุง v3.2.5
- จัดหน้า Category / Studio / Actor / Tag / Page เป็นรายการ responsive พร้อมชื่อ, Slug, จำนวนโพสต์ และส่วนแก้ไขแบบ Dropdown
- กดจำนวนโพสต์เพื่อเปิดรายการที่เกี่ยวข้อง โดยผู้ดูแลเห็นสถานะเผยแพร่/ฉบับร่าง/ส่วนตัว
- เพิ่ม/ปรับ SEO Title, Meta Description, Index/Noindex และแม่แบบแยกตามประเภทหน้า
- เพิ่มปุ่มตัวแปรเฉพาะบริบท พร้อม Preview ที่ประมวลผลตัวแปรเป็นข้อความตัวอย่างจริง
- เพิ่ม SEO snippet preview แบบเรียลไทม์ พร้อมจำนวน grapheme หลายภาษาและความกว้างโดยประมาณเป็น px
- URL Inventory แสดงชื่อชนิดรายการและชื่อปลายทางควบคู่ URL ที่เข้ารหัส
- เพิ่ม Global Admin Quick Dock แบบแนวตั้ง มีหน้าบ้าน, หลังบ้าน, เขียนโพสต์, แก้ไขรายการปัจจุบัน, ล้าง AVSF HTML Cache, เปลี่ยนธีม, เปลี่ยนภาษา และออกจากระบบ
- ลบปุ่มเปลี่ยนภาษาซ้ำในเครื่องมือหลังบ้านที่ล็อกอินแล้ว โดยคงปุ่มภาษาส่วนกลางไว้
- Owner ใช้ตราหัวราชสีห์สวมมงกุฎโทนทองส้ม และกรอบชื่อพร้อมเอฟเฟกต์ ทั้งนี้ไม่เปลี่ยนสิทธิ์ RBAC เดิม
- เพิ่มกฎ Apache ใน avsf-storage/uploads/ เพื่อปฏิเสธการเรียกใช้ไฟล์สคริปต์โดยตรง

หมายเหตุสำคัญ
- ปุ่มล้างแคชล้างเฉพาะ AVSF internal HTML cache ไม่ได้ล้าง Browser, CDN, Hosting Cache หรือ OPcache
- Preview ของ Google เป็นการประมาณการ Google สามารถเขียน Title/Description ใหม่และแสดงความยาวต่างกันตามอุปกรณ์หรือคำค้นหาได้ ไม่มีระบบใดรับประกันว่าจะไม่ถูกตัดคำ
- มีการตรวจ PHP syntax ในแพ็กเกจ แต่ยังไม่ได้ทดสอบบน Hosting จริง, Lighthouse/PageSpeed จริง หรือการจัดทำดัชนีจาก Google ใน Production


รายการปรับปรุง v3.2.6
- ลดความกว้างบล็อกตัวเล่นบนคอมพิวเตอร์ 7px ต่อข้าง (รวม 14px) และจัดให้อยู่กึ่งกลาง โดยไม่เปลี่ยนขนาดบนมือถือ/แท็บเล็ต
- จัด Breadcrumb, หัวข้อ H1, ข้อมูลวันเผยแพร่/ยอดวิว และบล็อกคำอธิบาย ให้กว้างและตรงแนวเดียวกับ avsf-post-detail-layout
- เมื่อเป็นเลย์เอาต์โปสเตอร์แนวนอนแบบเต็มจอในอุปกรณ์ขนาดเล็ก ให้ส่วนหัวและคำอธิบายใช้แนวขอบแบบเดียวกัน
- เปลี่ยนเวอร์ชัน CSS เพื่อป้องกัน Browser ใช้ไฟล์เก่าจาก Cache
- ไม่มีการเปลี่ยนฐานข้อมูล โครงสร้าง URL หรือสิทธิ์ผู้ใช้

หมายเหตุ v3.2.6
- ระยะขอบตัวเล่น 7px ต่อด้านใช้เฉพาะ viewport ตั้งแต่ 1025px ขึ้นไป
- ต้องตรวจหน้าบทความจริงบน Browser และ Hosting ของเว็บไซต์หลังติดตั้ง เนื่องจากการแสดงผลอาจขึ้นกับโฆษณาด้านข้างและ CSS ที่ Hosting/Cache ใช้อยู่


รายการปรับปรุง v3.2.7
- แก้ Global Admin Quick Dock ให้เป็น Floating Overlay จริง ใช้ position: fixed และไม่จองพื้นที่ layout
- ยกเลิก padding-right บน body ที่เคยบีบความกว้างหน้าเว็บทั้ง Desktop และ Mobile
- ยกเลิก padding-right บน .avsf-admin-main ทุก breakpoint ที่เคยทำให้หน้า Admin ถูกดัน/เบียด
- คง dock ไว้เหนือเนื้อหาด้วย z-index สูง และคงปุ่ม/การตรวจสิทธิ์เดิม
- ใช้กฎร่วมชุดเดียวกันกับทุกหน้าบ้านที่ผู้ดูแลล็อกอินและหน้า Admin ที่โหลด global dock
- ไม่มีการเปลี่ยนฐานข้อมูล, URL, RBAC, เนื้อหา หรือไฟล์ uploads

หมายเหตุ v3.2.7
- เมนูลอยอาจซ้อนทับพื้นที่เนื้อหาด้านขวาตามธรรมชาติของ Floating Overlay แต่จะไม่เปลี่ยนความกว้างของ document หรือทำให้หน้าเลื่อนไปด้านข้าง
- ควรตรวจบนมือถือและคอมพิวเตอร์หลังติดตั้ง รวมถึงทดสอบการกดปุ่มในเมนูลอย


รุ่น v3.2.8 — ปรับบล็อกหัวเรื่องให้ตรงกับตัวเล่นวิดีโอ
- Breadcrumb, H1 และวันเผยแพร่/ยอดดู จะมีความกว้างและตำแหน่งตรงกับกรอบตัวเล่นจริง
- รองรับกรณีมีโฆษณาด้านข้างตัวเล่น และปรับใหม่เมื่อเปลี่ยนขนาดหน้าจอ/หมุนอุปกรณ์
- ไม่เปลี่ยนบล็อกคำอธิบาย รายละเอียดโพสต์ ฐานข้อมูล หรือ URL
